Rotary Encoder Operations & Quick Guide

Quick reference guide for operating the Osprey Controller using its tactile Rotary Encoder dial and high-contrast OLED display.

Rotate Knob (CW / CCW)

Scrolls smoothly through modes with animated carousel transitions on the OLED screen.

Encoder Dial (Short Click)

Toggles highlighted channel ON/OFF in manual mode, or activates power groups with delays.

Encoder Dial (Long Press)

Triggers STANDBY (Safe FIFO All OFF) or switches to MANUAL ALL ON.

Emergency Button (PBS-1)

Single-press triggers instant hardware override (0ms delay), shows 3s countdown popup, and stays locked in mode.

🛡️ Smart Audio Controller by OSPREY (Power Sequencer & Anti-Pop Protection):

When multi-channel MOSFET amplifiers, DSPs, inverters, and source units power on simultaneously, high inrush currents cause loud speaker cracks. The Osprey Sequencer coordinates power safely:

  • Soft-Start Startup (Entry Delay): Inverter & TV turn ON first (0.0s) → Mixer & Crossover (0.5s) → DSP wakes up cleanly (3.0s) → Heavy Sub & Vocal Amps turn on last (4.0s).
  • Safe FIFO Shutdown (Exit Delay): DSP cuts out instantly (0.0s) → Amplifiers power down → Mixers cut → Main inverters cut last (3.0s).
  • Visual Channel Badges: Solid Box = ON, Outlined + Center Dots = Delay Counting Down (Pending), Outlined = OFF.

Web Controller & Navigation Settings

How to configure device navigation, screen layouts, channel labels, fonts, screensaver, and persistent NVS memory options via Web Serial.

⚙️ Navigation & Layout Settings:
  • Menu Layout Style: Switch between Horizontal Flipper (centered mode card with left/right arrows) and Vertical Carousel (3-mode vertical selection).
  • Device Font Family: Choose the OLED screen navigation font: Helvetica (modern bold), Monospace (classic), or Profont (retro).
  • Long Press Threshold: Adjust how long to hold the dial to trigger Standby All OFF / All ON.
  • Auto Duration: Set how long auto-cycle modes run before stopping.
  • Screensaver Timeout: Set the inactivity time before the logo screensaver appears. Screensaver is automatically suppressed while any relay is active.
🏷️ Branding, Boot Text & Channel Labels:
  • Controller Boot Text: Customize the startup text displayed on the OLED screen when the device powers on.
  • Boot Text Font Style & Size: Choose how large the boot text appears — from compact (small) up to extra large.
  • Channel Labels: Rename Relay Channels 1–8 with descriptive names (e.g. TV, DSP, SUB AMP, VOCALS).
  • Menu Option Rearrangement: Use UP/DOWN arrows to reorder modes or remove unnecessary ones. Restore removed modes anytime via the "+ Add Option" dropdown.
  • Save & Sync: Click Save & Sync in the header to store your settings on the device.
⚡ Relay Channel Wiring:
  • The controller has 8 independent relay channels (CH 1–8) for switching AC or DC electrical loads.
  • Each channel uses Common (COM) and Normally Open (NO) screw terminals.
  • Connect the Live/Positive wire of your load through the relay contacts. Neutral/Ground bypass the controller directly.
  • Always disconnect line power before connecting or adjusting wiring.
